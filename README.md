# 長洲足印

以傾斜地圖閱讀長洲的三條步行路線。介面為繁體中文，設計與文字皆為原創，並非任何現成步行網站的複本。

## 線上版

GitHub Pages：<https://hkrgb.github.io/cheung-chau-walk/>（沒有 serve.py，會自動改用原圖磚網址）。

後台管理員：只限 `info@rgb-workshop.com`（Firebase 專案 `cheung-chau-map-rgb`）。

## 如何開啟（建議）

在這個資料夾啟動內建的靜態伺服器兼圖磚代理：

```bash
cd /workspace/cheung-chau-walk
python3 serve.py
```

然後用瀏覽器打開 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。

為什麼要用 `serve.py`，而不是一般的 `python3 -m http.server`？有些瀏覽器環境（例如本機的沙盒 Chrome）連不上 `tiles.openfreemap.org` 這類圖磚主機，畫面會一片空白。`serve.py` 會把樣式、矢量圖磚、字型、雪碧圖，以及地形圖磚，經 `/proxy/<主機>/<路徑>` 由本機轉發；樣式與 TileJSON 裡的絕對網址也會被改寫成本機代理。伺服器端用 `curl` 能連到的位址，瀏覽器就能畫出來。

頁面會先打 `/proxy/health`：有回應就走代理；你在自己的電腦直接開檔案，或用其他靜態伺服器，則仍用原網址，不受影響。

也可以指定埠口：

```bash
python3 serve.py --port 9000
```

不需要安裝 npm，也沒有建置步驟。電腦仍需能上網，因為代理要去上游取圖。

## 包含什麼

- 一張以長洲為中心的互動地圖（約北緯 22.208、東經 114.029），預設傾斜鏡頭。
- 底圖可切換：**標準**（OpenFreeMap Liberty）、**地圖**／**航照**（地政總署）、**手繪風**（自製紙質虛線樣式，同樣用 OpenFreeMap 矢量、免 API key）、以及可選的 **手繪圖**（自備 JPG）。另加公開 Terrarium 高程（手繪圖除外）。
- 內置觀光路線（西灣、北眺亭）。選取路線會畫出路徑與站點；點站名或地圖標記會飛到該處，並打開側欄。
- 手機版（闊度 ≤820px，或橫向矮螢幕）：地圖鋪滿全屏，路線面板變成底部抽屜，可拖動或輕按把手，在「收起／半開／全開」之間切換。收起時只顯示標題與目前路線；半開時可橫向揀選路線、看站點列表；點站點後，資料卡在抽屜內顯示（附相片縮圖，按一下放大），地圖保留約 55% 以上的畫面，鏡頭會把標記置於可見範圍中央。橫向手機的抽屜靠左。桌面版外觀不變。
- 任何站點都可以附一張相片（`photo` 欄位），會顯示在資訊卡上，站點列表也會出現縮圖。


## 手繪底圖

地圖工具列可切換「標準｜地圖｜航照｜手繪風｜手繪圖」。

1. **手繪風**：即開即用，無需額外檔案（OpenFreeMap 矢量 + 紙色／虛線樣式）。
2. **手繪圖**：把你的手繪地圖 JPG 放到 `images/hand-map.jpg` 後重新整理；檔案存在才會顯示「手繪圖」按鈕。對位範圍在 `map-core.js` 的 `HAND_MAP.bounds`（目前對準衛星導出範圍：西 114.015、南 22.195、東 114.042、北 22.225）。若圖裁切不同，可改 `HAND_MAP.bounds`。

## 往聖方濟校園（明愛陳震夏郊野學園）

這條路線依照明愛陳震夏郊野學園的〈Route to St. Francis Campus〉路線圖編排，共九站：長洲渡輪碼頭 → 東灣路 → 東灣海灘（長洲東堤路口）→ 直升機坪・黑排路 → 觀音灣泳灘更衣室 → 觀音灣變電站・明暉路口 → 明暉路垃圾站 → 芝麻坑路分岔口 → 聖方濟校園。

- 每站的中英文指示照錄路線圖原文。終點附地址（香港長洲芝麻坑路三十九號）及電話（2981 1899）。
- 站點座標取自開放街圖的道路、直升機坪與「明愛陳震夏郊野學園」節點。開放街圖沒有標示中央廣場、觀音灣變電站及明暉路垃圾站，所以這幾處按路線圖位置放在相關道路上，屬約數。
- 這條路線的路徑線是用開放街圖步行路由（routing.openstreetmap.de）沿真實道路計算，約 1.4 公里，不是直線連接。
- `images/st-francis/` 內的相片全部取自該路線圖，沒有使用其他網站的圖片。相片及路線來源：明愛陳震夏郊野學園路線圖。校園相片是路線圖上的小圖，解像度較低。

## 座標是約數

站點經緯度來自開放街圖地名，以及維基百科等頁面列出的座標，已四捨五入。首三條路線的連線只表達步行順序，會刻意偏離海岸一點以免畫進海裡；往聖方濟校園一線則沿開放街圖道路繪畫。兩者都**不是**康樂及文化事務署或任何機構的官方步道軌跡。狹窄的啞鈴桿、灘邊與山徑，實地請跟路牌與現場告示。

長洲石刻一站要特別留意：古物古蹟辦事處頁面備註目前未有路徑直達，出發前請再查該處最新交通說明。

張保仔洞地面濕滑、光線昏暗，頁面只作位置與公開背景說明，不是進入岩洞的安全指引。
